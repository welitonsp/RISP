# RISP — Relatório de Indicadores Criminais

Site institucional responsivo para apresentação do Relatório de Auditoria dos
Indicadores Criminais da 19ª RISP — Caldas Novas.

## Conteúdo

- relatório completo adaptado para desktop e dispositivos móveis;
- navegação rápida entre as seções;
- tabelas e gráficos preservados em telas menores;
- opção de impressão ou geração de PDF pelo navegador;
- publicação com acesso privado por se tratar de documento restrito.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run build
```
